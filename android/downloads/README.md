# Install the Android demonstration app

[Download SyllabusToSong-v1.0-sunrise.apk](https://github.com/TechWhizSS/Intelligent_Tutoring/raw/refs/heads/codex/development/android/downloads/SyllabusToSong-v1.0-sunrise.apk)

Open the link in Chrome on an **Android 8.0+ phone**, download the APK, then open it from Downloads and follow Android's installation prompt. If GitHub asks, sign in to the account with access to this repository. For a blocked direct download, open the [APK's GitHub page](https://github.com/TechWhizSS/Intelligent_Tutoring/blob/codex/development/android/downloads/SyllabusToSong-v1.0-sunrise.apk) and tap **Download raw**.

The APK is debug-signed for a college demonstration. A previously installed copy signed with a different developer key must be uninstalled before this one can install; export recordings you want to preserve first. This is an Android APK, not an iPhone app.

Tap **Try the sample student account**. Notes, quizzes, drafts and the library work locally. For actual AI sung audio connect a running GPU under **More → Music connection**, or use **Generate with Lyria** and import the permitted download. A GPU session and generation/listening test remain necessary; no actual generated song is bundled or claimed verified.
