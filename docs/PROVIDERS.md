# Gemini music handoff

Gemini is the only music-generation option in the current website interface.
**Generate with Lyria** copies a source-linked chapter prompt, saves edited lyrics
when a draft exists, and opens https://gemini.google.com/app in the same tab.
Select **Create music**, paste the prompt and send. Clipboard denial reveals
selectable text and a direct link. Mobile and desktop use the same flow.

There is no verified supported native link to prefill Gemini or select its music
mode. No iframe, automatic Generate click, Google credential collection or
automatic audio import is implemented. No music API key is requested. Gemini
controls account eligibility, music availability, free allowances and output
length. See https://support.google.com/gemini/answer/16901237 .

Download a permitted MP3 from Gemini and attach it to a saved lyric draft for
playback in the website. Attachments are labelled user supplied; the app does
not claim it generated them. Review academic meaning and formula pronunciation.

The removed music service has no key form, account-check route, generation
adapter or outbound requests. Its previously saved private credential is deleted
when the authenticated visitor loads provider status after deployment.

Legacy ACE-Step CPU/GPU backend routes and developer scripts are retained for
compatibility with existing records and protocol tests; they are not exposed as
music-generation options in the current interface. Their model setup and GPU
execution have not produced a verified educational song here.

**Verification boundary:** tests verify clipboard/navigation, saved lyrics,
authentication, persistence and playback of isolated audio fixtures. No actual
educational song or its vocals/musical quality has been verified through this
project. Fixtures are never bundled or presented as generated songs.
